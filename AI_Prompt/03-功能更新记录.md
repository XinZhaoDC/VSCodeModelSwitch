# VSCodeModelSwitch 功能更新记录

本文件记录每次仓库更新的用户可见功能、配置影响和验证结果。它不是
Git 提交的替代品；每条记录应能追溯到对应 commit、VSIX 和测试命令。

## 记录规则

每次功能更新至少记录：

- 日期和版本号。
- 用户可见功能变化。
- 修改的主要文件或模块。
- 配置文件、SecretStorage、环境变量是否变化。
- 是否需要迁移、重新输入 key 或重新安装 VSIX。
- 执行过的检查、编译、打包和运行验证。
- 已知限制、未验证范围和回滚版本。

不要在本文件或 Git 提交中写入真实 API key、OAuth token、Cookie、完整
认证配置或带密钥的日志。

## v0.1.0 - 基线版本

### 功能

- 管理 Claude Code 和 Codex Provider。
- 请求并选择 Provider 模型列表。
- 使用 VS Code SecretStorage 保存 key。
- 在状态栏显示当前 Provider 和模型。
- 为新建 VS Code 终端注入 CLI 环境变量。
- 可选同步 CLI 配置文件。
- 支持公共配置导入和导出。
- 提供 sandbox 配置目标。

### 私有版本身份

- 扩展包名：`vscodemodelswitch`。
- 显示名称：`VSCodeModelSwitch`。
- 扩展 ID：`xinzhaodc.vscodemodelswitch`。
- 私有源码仓库：`XinZhaoDC/VSModelSwitch`。
- 原始源码对照目录：`original/`。
